# e-shop
Проект e-shop представляет собой интернет магазин, проект содержит 3 функциональных модуля и 3 тестовых.

## Содержание
- [Использование](#начало-работы)
- [Тестирование](#тестирование)
- [Команда проекта](#команда-проекта)

## Использование
Чтобы установить проект себе достаточно выполнить в терминале команду:
*git clone git@github.com:KonstantinKorovin/e_shop.git*

### Установка зависимостей
Для установки зависимостей, выполните команду:
*pip install -r requirments.txt*

## Тестирование
проект протестирован с помощью библиотеки '**pytest**' чтобы запуcтить тесты нужно выполнить эту команду прямиком в терминале,
чтобы узнать покрытие тестами программы выполните команду '**poetry run pytest --cov**'
